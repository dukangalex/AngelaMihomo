## О проекте

**Angela Mihomo** — кроссплатформенный прокси-клиент на ядре [Mihomo](https://github.com/MetaCubeX/mihomo) с акцентом на цепочечные прокси, системную защиту от утечек и работу «из коробки». Разрабатывается и публикуется независимо под лицензией GPL-3.0.

Анонсы релизов: https://t.me/AngelaNexus

* **Цепочечные прокси: входной и выходной переходы могут быть группами прокси; выход можно выбрать из другого профиля; пустая входная группа автоматически блокирует прямой обход.**
* **Системная защита от утечек: блокировка WebRTC, прямой доступ к публичным DNS Китая, блокировка рекламы и другие явные правила, объединённые с политикой цепочки.**
* **Независимый идентификатор пакета: Android application id `app.angelabettbox`, установка рядом с другими клиентами; id стабилен, обновления ставятся поверх.**
* **Ядро и данные: ядро соответствует официальным релизам Mihomo (сейчас v1.19.33), встроенные данные правил — из официального источника MetaCubeX/meta-rules-dat.**

## Загрузки

Пакеты для вашей платформы — на странице **[Releases](https://github.com/dukangalex/AngelaMihomo/releases)** этого репозитория (Windows, Linux, macOS, Android, Android TV).

**Миграция с другой сборки (Android)**: начиная с v1.19.7-chain.1 приложение использует собственное имя пакета и ставится рядом с другими сборками; сначала экспортируйте резервную копию в другом приложении, затем импортируйте её здесь.
